# Age rating answers

The pictures are generated from whatever the person types. The API refuses prompts with obscene words before anything
is made, and every picture can be reported in the app; there is no image-level check. Pictures are private to the
account: the app has no sharing between users, no chat and no public feed. The terms require users to be 13 or over.
So the answers allow for mild, occasional themes in pictures and aim for **13+**. If a reviewer asks for a higher
rating, accept 16+ or 18+ rather than argue.
